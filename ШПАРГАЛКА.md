# 🎯 ШПАРГАЛКА - Быстрый запуск

## 🚀 Самый быстрый способ

```bash
cd /root/daggervpn
./start.sh
```

Всё! Скрипт сам:
- Настроит базу данных
- Установит зависимости
- Запустит миграции
- Запустит бота и webhook

---

## 🔧 Ручной запуск (если start.sh не работает)

### 1. Исправить базу данных

```bash
su - postgres -c "psql -c \"ALTER USER daggervpn WITH PASSWORD 'changeme';\""
```

### 2. Установить зависимости

```bash
pip install -r requirements.txt
```

### 3. Запустить миграции

```bash
alembic upgrade head
```

### 4. Запустить бота

```bash
screen -S bot -dm python -m app.main
screen -S webhook -dm python -m app.webhook
```

---

## 📋 Проверка работы

```bash
# Список screen сессий
screen -ls

# Подключиться к боту
screen -r bot

# Подключиться к webhook
screen -r webhook

# Проверить webhook
curl http://localhost:8000/health
```

## 🆘 Помощь

### База данных не подключается

```bash
su - postgres -c "psql -c \"ALTER USER daggervpn WITH PASSWORD 'changeme';\""
python test_db_connection.py
```

### Порт 8000 занят

```bash
lsof -ti:8000 | xargs kill -9
```

### Бот не запускается

```bash
pkill -f "python -m app"
python -m app.main  # запустить в текущем терминале, чтобы увидеть ошибки
```
