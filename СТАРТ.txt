===============================================

1️⃣  ЗАПУСК ОДНОЙ КОМАНДОЙ:

   cd /root/daggervpn && ./start.sh

===============================================

2️⃣  ПРОВЕРКА:

   screen -ls                  # Список процессов
   curl localhost:8000/health  # Проверка webhook

===============================================

3️⃣  НАСТРОЙКА PLATEGA:

   nano .env

   Замените:
   PLATEGA_MERCHANT_ID=получите_на_platega.io
   PLATEGA_SECRET=получите_на_platega.io

===============================================

4️⃣  АДМИНКА:

   Админка → 🔑 Все ключи → Выбрать ключ
   → ➕ Добавить дни → Ввести количество

===============================================

📋 ПОЛЕЗНЫЕ КОМАНДЫ:

   screen -r bot       # Подключиться к боту
   screen -r webhook   # Подключиться к webhook

   pkill -f "python -m app"  # Остановить всё
