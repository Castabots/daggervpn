## 4. ✅ Добавить платёжную систему Platega

**Статус:** ✅ Выполнено

**Что реализовано:**

### 4.1 Провайдер Platega
Создан полноценный провайдер `PlategaProvider`:
- `create_payment()` - создание платежа через Platega API
- `get_payment_status()` - проверка статуса платежа
- `verify_webhook()` - верификация webhook уведомлений
- Аутентификация через `X-MerchantId` и `X-Secret` заголовки
- Маппинг статусов Platega → внутренние статусы
- Обработка ошибок и логирование

### 4.2 Webhook сервер
Создан FastAPI сервер для приёма webhook:
- Endpoint: `POST /webhook/platega`
- Универсальный endpoint: `POST /webhook/payment`
- Health check: `GET /health`
- Запускается на порту 8000
- Готов для запуска через Docker

### 4.3 Интеграция с ботом
- Обновлён обработчик покупки `tariff_confirmed()`
- При выборе тарифа создаётся реальный платёж через Platega
- Пользователь получает кнопку "💳 Оплатить" с прямой ссылкой
- После оплаты webhook автоматически:
  - Обрабатывает платёж
  - Создаёт ключ в панели Remnawave
  - Отправляет ключ пользователю
  - Начисляет реферальные бонусы
  - Учитывает промокоды

### 4.4 Конфигурация
Добавлены настройки в `.env`:
```env

PLATEGA_MERCHANT_ID=ваш_merchant_id
PLATEGA_SECRET=ваш_secret_key
```

### 4.5 Docker

## ⚠️ Важные замечания

### Platega API
Реализация основана на типичной структуре платёжных API. После получения **полной документации Platega** может потребоваться корректировка:

1. **Структура запроса создания платежа:**
   - Названия полей (amount, orderId, metadata)
   - Формат данных

2. **Структура ответа API:**
   - Названия полей (id/invoiceId/paymentId)
   - paymentUrl/url/link

3. **Маппинг статусов:**
   - Текущий: new→pending, paid→succeeded, failed→failed
   - Может потребоваться корректировка

4. **Верификация webhook:**
   - Метод подписи (HMAC-SHA256)
   - Формат канонической строки
   - Название заголовка с подписью

**Где корректировать:** `app/services/platega_provider.py`

### Тестирование
Для локального тестирования webhook используйте ngrok:
```bash
ngrok http 8000
```
