# DaggerVPN Bot - Обновления

## Что нового

### 1. Изменено расписание напоминаний
- **Раньше**: уведомления приходили за 7, 3 и 1 день до истечения подписки
- **Теперь**: уведомления приходят только за 3 и 1 день до истечения

### 2. Админка для управления ключами

Добавлен новый раздел **"🔑 Все ключи"** в админке:
- Просмотр всех ключей пользователей
- Детальная информация по каждому ключу
- **Добавление дней к подписке** - теперь администратор может продлить любой ключ на указанное количество дней
- Кликабельная ссылка на ключ прямо из админки

#### Как пользоваться:
1. Зайдите в админку → "🔑 Все ключи"
2. Выберите нужный ключ из списка
3. Нажмите "➕ Добавить дни"
4. Введите количество дней
5. Готово! Дата истечения обновится и в боте, и в панели Remnawave

### 3. Интеграция платёжной системы Platega

Добавлена поддержка платёжной системы Platega для приёма оплаты.

#### Настройка Platega:

1. **Получите учётные данные:**
   - Зарегистрируйтесь на https://platega.io/
   - Получите `MERCHANT_ID` и `SECRET` в личном кабинете

2. **Настройте .env файл:**
   ```env
   PAYMENT_PROVIDER=platega
   PLATEGA_MERCHANT_ID=ваш_merchant_id
   PLATEGA_SECRET=ваш_secret_key
   ```

3. **Запустите webhook сервер:**
   
   Webhook сервер нужен для получения уведомлений об оплате от Platega.
   
   ```bash
   # В отдельном терминале
   python -m app.webhook
   ```
   
   Сервер запустится на порту 8000.

4. **Настройте webhook в личном кабинете Platega:**
   
   URL webhook: `https://ваш-домен.com/webhook/platega`
   
   ⚠️ **Важно**: 
   - URL должен быть доступен из интернета
   - Рекомендуется использовать HTTPS
   - Используйте nginx или другой reverse proxy для проксирования на порт 8000

#### Пример конфигурации nginx:

```nginx
server {
    listen 80;
    server_name ваш-домен.com;

    location /webhook/ {
        proxy_pass http://localhost:8000/webhook/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}
```

#### Для разработки (локальное тестирование):

Используйте ngrok для создания публичного URL:
```bash
ngrok http 8000
```

Затем используйте полученный URL в настройках webhook Platega:
```
https://ваш-ngrok-url.ngrok.io/webhook/platega
```

## Установка и запуск

### 1. Установите зависимости:
```bash
pip install -r requirements.txt
```

### 2. Настройте .env:
Скопируйте `.env.example` в `.env` и заполните все поля:
```bash
cp .env.example .env
nano .env
```

### 3. Запустите бота:
```bash
python -m app.main
```

### 4. Запустите webhook сервер (если используете Platega):
```bash
# В отдельном терминале
python -m app.webhook
```

## Docker

Если используете Docker, обновите docker-compose.yml:

```yaml
services:
  bot:
    # ... существующая конфигурация
    
  webhook:
    build: .
    command: python -m app.webhook
    ports:
      - "8000:8000"
    env_file:
      - .env
    depends_on:
      - db
```
